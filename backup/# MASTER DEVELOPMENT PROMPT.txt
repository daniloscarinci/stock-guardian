# MASTER DEVELOPMENT PROMPT

## Stock Guardian — Professional Offline-First Survival & Logistics Management Application

### ROLE

You are a senior software architect, product designer, UX engineer, database engineer, security engineer, QA engineer, and offline-first application specialist.

Your task is to transform the supplied reference application:

**`End_of_world_V11-Pro_Upgraded.html`**

into a **professional, production-quality, fully offline application** suitable for installation and daily use on desktop and mobile devices.

Do NOT merely wrap the existing HTML in an Electron/WebView container.

You must analyze the existing application, preserve its useful functionality and data model, then redesign and rebuild it as a maintainable, scalable application.

# 29. DATA MIGRATION FROM ORIGINAL HTML

```javascript

    expiry,
    cat
}
```

must be mapped into the new schema.

Example:

```text
Legacy name       → InventoryItem.name
Legacy qty        → InventoryItem.quantity
Legacy loc        → Location
Legacy expiry     → InventoryItem.expirationDate
Legacy cat        → Category
```

Do not lose information.

If a field cannot be mapped automatically, preserve it in a migration notes field rather than deleting it.
